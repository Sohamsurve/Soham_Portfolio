# Soham Surve - Portfolio

A modern, responsive portfolio website showcasing my projects and skills as a Full-Stack Developer.

## 🚀 Features

- Responsive design for all devices
- Smooth animations and interactive elements
- Real project showcase from GitHub
- Contact form with validation
- Modern UI/UX design

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Animations, Grid, Flexbox
- **JavaScript** - Interactive functionality
- **Font Awesome** - Icons
- **Google Fonts** - Typography

## 📂 Structure

```
├── index.html              # Main page
├── styles/
│   ├── main.css           # Main styles
│   └── animations.css     # Animations
├── scripts/
│   ├── main.js           # Core functionality
│   └── animations.js     # Advanced effects
└── README.md
```

## 🚀 Quick Start

1. Open `index.html` in your browser
2. Or serve locally: `python3 -m http.server 8080`
3. Visit `http://localhost:8080`
